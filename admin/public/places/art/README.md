# Place art

Brand art for places and sessions with no photo of their own (the app picks one per sport in
`src/lib/sportPhotos.ts`). Each picture is a sport icon on an Operation Beast colourway: the
brand's own sport icons (Brand Guidelines 2025, page 44) and game-icons.net silhouettes by Lorc,
Delapouite, Skoll and Carl Olsen (CC BY 3.0, credited in the app's Settings). Nothing is drawn by
hand. To change them, edit and run `node scripts/brand/place-art/generate.js`.
